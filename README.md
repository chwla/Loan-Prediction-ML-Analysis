# Loan Prediction ML Analysis

This project applies a full machine learning pipeline to a real-world loan prediction dataset, demonstrating regression, classification, and clustering techniques using Python and scikit-learn.

## Overview

- **Goal:** Analyze and model loan applicant data for:
  - Predicting loan amounts (regression)
  - Predicting loan approval status (classification)
  - Segmenting applicants into clusters (unsupervised learning)

- **Key Steps:**
  - Data cleaning and preprocessing (handle missing values, select features, standardize)
  - Dimensionality reduction with PCA
  - Model training and evaluation for regression and classification
  - Clustering analysis and metrics comparison

## Features

- **Regression Models:** Linear Regression, Random Forest, Extra Trees, AdaBoost, XGBoost, NGBoost
- **Classification Models:** Logistic Regression, Naive Bayes, KNN, SVM, Decision Tree, Neural Network
- **Clustering Algorithms:** K-Means, Gaussian Mixture (EM), K-Medoids
- **Evaluation Metrics:** RMSE, MAE, Precision, Recall, F1-Score, Silhouette Score, SSE, BetaCV, Dunn Index, Hubert’s Statistic
- **Preprocessing:** Z-score normalization, PCA for dimensionality reduction
